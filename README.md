# 3D KMG Measurement Simulator\n\n## Overview\n\nA photorealistic 3D Coordinate Measurement Machine (KMG) simulator built with Three.js featuring:\n\n- **3D Interactive Probe Control** - Mouse/touch-based tactile probe manipulation\n- **PBR Materials** - Realistic metallic-roughness physically-based rendering\n- **GLTF Model Support** - Load professional probe and part models\n- **5x5 Quiz System** - 25 interactive measurement questions with difficulty-based scoring\n- **Real-time Measurements** - Animated feedback and tolerance checking\n- **Responsive Design** - Works on desktop and mobile devices\n\n## Features\n\n### 3D Scene\n- Professional lab lighting setup (key, fill, back, ambient, point lights)\n- Dynamic shadow mapping\n- PBR material system with metallic/roughness controls\n- Interactive camera and probe positioning\n- Real-time dimension feedback\n\n### Quiz System\n- 5 dimensions × 5 difficulty levels = 25 questions\n- Dynamically generated measurement questions\n- Difficulty-based scoring (Easy: 10pts, Medium: 20pts, Hard: 30pts)\n- Visual feedback for correct/incorrect answers\n- Score tracking and progression\n\n### Controls\n- **Mouse Drag**: Move probe in X/Y plane\n- **Scroll Wheel**: Move probe along Z-axis\n- **Touch**: Mobile-friendly probe control\n- **Click on Part**: Take measurements\n\n## Project Structure\n\n```\n├── index.html\n├── src/\n│   ├── main.js\n│   ├── styles.css\n│   ├── controllers/\n│   │   └── ProbeController.js\n│   ├── systems/\n│   │   ├── MeasurementSystem.js\n│   │   └── QuizSystem.js\n│   ├── scene/\n│   │   └── SceneSetup.js\n│   └── materials/\n│       └── PBRMaterialManager.js\n├── models/\n│   ├── probe.glb\n│   └── part.glb\n├── package.json\n├── vite.config.js\n└── README.md\n```\n\n## Installation\n\n```bash\n# Install dependencies\nnpm install\n\n# Run development server\nnpm start\n\n# Build for production\nnpm run build\n```\n\n## Usage\n\n1. **Load the application** in your web browser\n2. **Move the probe** using mouse drag (X/Y) and scroll (Z)\n3. **Click on the part** to measure dimensions\n4. **Start Quiz** to test your measurement knowledge\n5. **Answer questions** about critical dimensions with scoring\n\n## GLTF Model Integration\n\nPlace your probe and part models in `models/`:\n\n```\nmodels/\n├── probe.glb      # Probe model with tip and shaft\n└── part.glb       # Part model with body and features\n```\n\nThe system automatically creates mock models if GLTF files aren't found.\n\n## Material Properties\n\nPBR materials are configured with:\n- **Base Color**: Main surface color\n- **Metallic**: 0-1 scale (0=dielectric, 1=metal)\n- **Roughness**: 0-1 scale (0=mirror, 1=matte)\n- **Emissive**: Glow intensity\n\n## Quiz Scoring System\n\n| Difficulty | Points | Questions |\n|------------|--------|----------|\n| Easy       | 10     | 25       |\n| Medium     | 20     | 25       |\n| Hard       | 30     | 25       |\n\n**Maximum Score**: 600 points (all correct, all hard)\n\n## Technical Details\n\n### Three.js Version\n- r128+ (includes GLTFLoader)\n\n### Rendering Settings\n- **Tone Mapping**:
